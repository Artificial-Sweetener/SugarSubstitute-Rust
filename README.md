# SugarSubstitute

**Not ready for use.** SugarSubstitute is in active development. Please don't download, build or install it yet. There are no releases, and nothing here is supported.

The repository holds two components:

- `Sugar/`: the SugarCubes node pack for ComfyUI. Install SugarCubes from ComfyUI Manager or the Comfy Registry, not from this repository.
- `Substitute/`: the SugarSubstitute desktop app for Windows.
